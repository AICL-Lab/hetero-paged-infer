# 内存效率

PagedAttention 显著降低内存浪费，相比传统分配策略。

## 问题：内存碎片

传统 LLM 服务系统为每个请求预分配固定大小的内存块：

- **结果**：40-60% 的 GPU 内存浪费在未使用的槽位上

## 解决方案：PagedAttention

PagedAttention 将 KV Cache 分成固定大小的块，按需分配：

- **结果**：内存浪费限制在每个序列 < 一个块 (<5%)

## 量化对比

| 场景 | 静态 | 动态 | PagedAttention |
|------|:----:|:----:|:--------------:|
| 100 短请求 (平均 50 tokens) | 58% 浪费 | 28% 浪费 | **3% 浪费** |
| 10 长请求 (平均 1000 tokens) | 45% 浪费 | 22% 浪费 | **4% 浪费** |
| 混合负载 (可变长度) | 52% 浪费 | 25% 浪费 | **4% 浪费** |
